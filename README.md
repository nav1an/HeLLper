# HeLLper

Десктопная утилита для упрощения работы QA.

## Возможности
- Форматирование JSON
- Генератор UUID
- Переводчик
- Напоминания
- Буфер обмена
- Счётчик символов
- Генератор банковских карт

## Установка

1. Клонируй репозиторий:
   git clone https://github.com/nav1an/HeLLper.git

2. Перейди в папку проекта:
   cd HeLLper

3. Создай виртуальное окружение:
   python -m venv .venv

4. Активируй его:
   .venv\Scripts\activate

5. Установи зависимости:
   pip install -r requirements.txt

6. Запусти:
   python main.py
