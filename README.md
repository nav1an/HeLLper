# HeLLper

**Десктопная утилита для QA-инженеров, которая экономит твоё время и нервы.**

Хватит открывать 10 вкладок с генераторами UUID, тестовых карт и парсерами JSON!
HeLLper собирает все нужные инструменты в одном месте — всегда под рукой, прямо на рабочем столе.

---

## Что умеет HeLLper

### Инструменты для ежедневной работы QA:

- **Форматирование JSON** — вставь кривой JSON, получи красивый. Быстрая проверка ответов API
- **Генератор UUID** — генерируй UUID v4 одной кнопкой, копируй в буфер
- **Переводчик** — быстрый перевод текста без открытия Google Translate
- **Напоминания** — ставь напоминалки прямо в приложении, не теряй фокус
- **Буфер обмена** — история копирования, быстрый доступ к недавним текстам
- **Счётчик символов** — считай символы, слова, строки для тестовых данных
- **Генератор карт** — генерируй валидные номера карт (МИР, Visa, MasterCard) для тестирования платёжных систем

### Кастомизация:

- **7 цветовых тем** — тёмные и светлые, выбирай под настроение
- **Настраиваемые инструменты** — включай только то, что нужно, отключай лишнее
- **Часовые пояса** — работай с командами из разных стран
- **Автозапуск** — запускается вместе с Windows, всегда готов к работе

### Удобство:

- **Плавающая панель** — всегда на виду, не мешает работе
- **Закрепление** — зафиксируй панель, чтобы не убегала
- **Лёгкий вес** — не грузит систему, работает быстро

## Установка

### Требования:

- Windows 10/11
- Python 3.9 или выше
- Git (опционально, для клонирования)

### Способ 1: Через Git (рекомендуется)

1. Клонируй репозиторий:
   `git clone https://github.com/nav1an/HeLLper.git`

2. Перейди в папку проекта:
   `cd HeLLper`

3. Запусти:
   `run.bat`

Скрипт сам создаст виртуальное окружение, установит зависимости и откроет приложение.

### Способ 2: Скачать ZIP

1. Нажми зелёную кнопку **Code** → **Download ZIP**
2. Распакуй архив в удобную папку
3. Запусти `run.bat` двойным кликом

## Как использовать

### Первый запуск

1. Запусти `run.bat` — он сам активирует виртуальное окружение и откроет приложение
2. Приложение появится в верхней части экрана как небольшая панель
3. Нажми на стрелку **▼** в правом верхнем углу, чтобы открыть меню инструментов

### Навигация

- **Боковая панель слева** — иконки инструментов, кликай для переключения
- **Верхняя панель** — время, название приложения, кнопки управления
- **Область контента** — здесь отображается выбранный инструмент

### Основные действия

- **Переключение инструментов** — кликай по иконкам в боковой панели
- **Закрытие меню** — нажми стрелку или кликни вне меню
- **Закрепление панели** — нажми кнопку с иконкой булавки, чтобы панель не убегала при потере фокуса
- **Настройки** — кликни по иконке шестерёнки внизу боковой панели

### Настройка под себя

В разделе **Настройки** ты можешь:

1. **Выбрать часовой пояс** — для корректного отображения времени
2. **Включить/выключить инструменты** — оставь только нужные, убери лишнее
3. **Сменить тему** — 8 цветовых схем на выбор
4. **Настроить автозапуск** — чтобы HeLLper запускался вместе с Windows

## Структура проекта

    HeLLper/
    ├── main.py                  # Точка входа
    ├── run.bat                  # Скрипт запуска (используй его!)
    ├── requirements.txt         # Зависимости Python
    ├── config.py                # Основные настройки приложения
    ├── build.bat                # Скрипт для сборки в .exe
    ├── core/                    # Логика приложения
    │   ├── translator.py        # Сервис перевода
    │   ├── clipboard.py         # Работа с буфером обмена
    │   ├── reminder_service.py  # Напоминания
    │   ├── theme_manager.py     # Управление темами
    │   └── timezones.py         # Часовые пояса
    ├── ui/                      # Интерфейс
    │   ├── topbar_window.py     # Главное окно
    │   ├── settings_panel.py    # Панель настроек
    │   ├── translator_panel.py  # Переводчик
    │   ├── clipboard_panel.py   # Буфер обмена
    │   ├── json_panel.py        # JSON форматтер
    │   ├── uuid_panel.py        # Генератор UUID
    │   ├── reminder_panel.py    # Напоминания
    │   ├── char_counter_panel.py # Счётчик символов
    │   └── card_generator_panel.py # Генератор карт
    └── icon.ico                 # Иконка приложения
